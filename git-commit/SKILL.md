# 智能 Git 提交命令说明

自动化执行代码暂存与中文智能提交。

## 执行流程

1. **状态检查与暂存**
   - 检查当前是否为 Git 仓库。
   - 自动执行 `git add -A` 暂存所有变更。

2. **变更智能分析**
   - 执行 `git diff --cached --stat` 分析变更规模与受影响的模块。
   - 判定**变更类型（Type）**：
     - `feat`: 新增功能/新文件
     - `fix`: 修复 Bug/异常修改
     - `refactor`: 代码重构（不增加功能，不修复Bug的代码变动）
     - `docs`: 文档、README 变更
     - `style`: 代码格式调整（不影响运行逻辑的空格、分号等修改）
     - `test`: 增加或修改测试用例
     - `chore`: 构建流程、依赖、项目配置变更（如 .gitignore, package.json）
     - `perf`: 性能、体验优化

3. **生成提交信息（Commit Message）**
   - **格式规范**：`<type>(<scope>): <中文描述>`
   - **要求**：
     - `scope`（可选）：填写受影响的模块、组件或核心文件（如 `用户模块`, `api`, `ui`, `首页`）。
     - `中文描述`：使用清晰的中文动宾短语，**句首不用大写，末尾不加句号**，整体控制在 50 字以内。
     - 杜绝假大空的描述（如“更新了代码”、“修复了Bug”），需指出具体干了什么。
   - **示例**：
     - `feat(登录): 新增 JWT 登录验证与拦截器`
     - `fix(首页): 修复轮播图在移动端白屏的问题`
     - `chore(依赖): 升级 axios 到最新版本`

4. **执行提交**
   - 如果用户输入了自定义参数 `$ARGUMENTS`，优先使用用户输入的信息。
   - 否则，使用自动生成的中文规范信息。
   - 执行 `git commit -m "<message>"`。

5. **后置确认**
   - 输出最终的提交信息与 Commit SHA，确认工作区干净。

## 使用示例

* `/git-commit` —— 自动分析所有变更，生成中文提交信息并提交。
* `/git-commit "fix(全局): 紧急修复生产环境跨域问题"` —— 使用自定义的中文信息直接提交。
